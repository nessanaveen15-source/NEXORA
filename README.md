 NEXORA

 An Explainable and Risk-Aware Framework for Monitoring Machine Learning Models and Selecting Adaptive Recovery Strategies Under Data Drift

 Overview

Nexora is a machine learning research project focused on monitoring model performance, detecting data drift and identifying suitable recovery strategies when real-world data patterns change.

The framework uses financial fraud detection as its experimental application to study how changing transaction patterns can affect machine learning model reliability.

 Problem Statement

Machine learning models may experience performance degradation when incoming data distributions change over time.

Nexora aims to address this challenge through continuous monitoring, explainable analysis, risk quantification and adaptive recovery recommendations.

 Key Objectives

- Develop a baseline machine learning model for fraud detection.
- Monitor changes in incoming data distributions.
- Detect data drift and investigate model degradation.
- Explain model predictions using Explainable AI techniques.
- Quantify the potential risk associated with model degradation.
- Evaluate suitable model recovery strategies.
